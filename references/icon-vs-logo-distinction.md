# Icon 与 LOGO 综合区分 & 通用设计准则

> 来源：从原始 Icon 与 Logo 区分资料整理，并已内化为本 skill 的参考手册。

**文档类型**：配套统一设计规范

**衔接文档**：[图标 Icon 设计指南](icon-design-guide.md)、[LOGO 设计指南](logo-design-guide.md)

**核心目标**：明确二者定位边界、区分使用场景、提炼跨品类通用设计规则、统一团队执行标准，全程以用户视角为核心

---

## 一、核心定位与本质区分（底层差异）

### 1.1 定义与核心价值

| 维度 | Icon（图标） | LOGO（品牌标识） |
|------|-------------|-----------------|
| 核心属性 | 功能型视觉符号、交互语言 | 品牌身份符号、视觉资产 |
| 服务目标 | 提升操作效率、降低交互认知成本 | 强化品牌记忆、建立用户心智认知 |
| 核心作用 | 指引操作、表达功能 / 状态、辅助界面信息传递 | 区分品牌、传递品牌气质、建立信任与辨识度 |
| 生命周期 | 可随版本迭代、功能调整优化，变更频率较高 | 长期固定使用，追求稳定性，极少大幅改动 |
| 用户诉求 | 看得懂、点得准、用得顺手 | 记得住、分得清、感知匹配品牌定位 |

### 1.2 核心使用场景边界（严禁混用）

**Icon 专属场景**

- 界面控件：按钮、导航栏、工具栏、菜单、操作入口
- 状态提示：加载、成功、警告、空数据、权限标识
- 分类标签：内容分类、属性标记、功能分区
- 系统通用符号：返回、搜索、设置、分享等全局操作

**LOGO 专属场景**

- 品牌主视觉：官网头部、APP 启动页、名片、门头、户外广告
- 版权与归属：页面页脚、产品关于页、文件水印、宣传物料
- 身份标识：账号头像、品牌周边、包装、展会形象
- 独家区分：同赛道产品 / 企业之间的品牌差异化识别

**易混淆场景区分（正反示例）**

- ✅ **正确**：APP 桌面使用简化版 LOGO 作为应用图标（品牌身份 + 入口结合，行业通用做法）
- ❌ **错误**：用功能 Icon 替代品牌 LOGO 放在页面头部、宣传主视觉；用 LOGO 充当界面功能按钮

## 二、视觉形态与设计逻辑差异

### 2.1 造型设计逻辑

**Icon**

- 设计逻辑：标准化、通用化，遵循大众已形成的符号认知，不刻意追求独特性
- 造型要求：形态极简、轮廓直白，优先保证瞬间识别，允许同行业大量复用经典符号
- 细节约束：无复杂纹理、多层结构，适配极小尺寸与高密度界面排布

**LOGO**

- 设计逻辑：差异化、独有化，必须打造专属视觉特征，规避与竞品撞型
- 造型要求：保留 1 个核心记忆点，可做创意演绎，但不能牺牲基础识别性
- 细节约束：可在主体轮廓内做专属设计，但缩放至小尺寸（Favicon、头像）仍需完整可辨

### 2.2 风格与体系约束

#### 2.2.1 风格选择规则

**Icon**：风格跟随产品 UI 体系（线性 / 面性 / 线面结合），整套界面图标风格必须完全统一，服务于整体界面体验。

- ❌ **反面**：同一产品内混搭多种风格 Icon，造成界面视觉混乱。

**LOGO**：风格独立定义品牌气质，可与 UI 图标风格差异化，但二者视觉调性不能严重冲突。

- ✅ **正面**：科技品牌 LOGO 走极简几何风，配套 Icon 同步几何线条风格，整体协调统一。
- ❌ **反面**：轻奢优雅风 LOGO，搭配夸张童趣风 Icon，品牌视觉割裂。

#### 2.2.2 图形复杂度控制

- ✅ **Icon**：低复杂度，元素 ≤ 2 个，拒绝多余装饰，以功能表达为核心
- ✅ **LOGO**：中等复杂度，聚焦单一核心创意点，元素精简，不堆砌多重图形、文字、纹样
- ❌ **共性反面**：二者都禁止过度艺术化、碎片化、多层叠加造型，大幅增加用户识别与记忆成本

### 2.3 图文搭配规则

**Icon 图文组合**

- 高频通用 Icon：可纯图形展示；
- 低频、业务专属 Icon：强制搭配文字，消除理解门槛；
- 排布：图标在前、文字在后，间距固定，适配移动端触控与桌面端浏览。

**LOGO 图文组合**

- 标准形态：图形 + 品牌名称（中文 / 英文）固定比例、固定间距，形成唯一组合规范；
- 衍生形态：支持纯图形版、纯文字版，适配不同尺寸场景；
- 排布：横竖版本严格区分，禁止随意拉伸、拆分、重组。

## 三、色彩体系通用规则 & 差异化要求

### 3.1 全局通用色彩准则（Icon + LOGO 均强制执行）

**少色原则**：单款视觉主体色彩数量 ≤ 2 种主色，禁止五彩斑斓、高饱和乱色搭配。

**语义优先**：功能类视觉元素，色彩遵循大众通用语义：红 = 警示 / 删除、绿 = 成功 / 安全、黄 = 提醒。

**无障碍约束**：图形与背景对比度常规场景 ≥ 4.5:1，大尺寸图形 ≥ 3:1；深色 / 浅色模式下均保证清晰识别。

**单色适配**：必须支持黑白单色显示，去色后轮廓、结构、识别性不受破坏。

### 3.2 色彩使用差异化

**Icon 色彩**

- 主体色：以产品中性色（黑 / 灰）为主，仅状态类图标使用语义色；
- 品牌色：仅在选中、激活、高亮状态少量使用品牌主色，不大面积铺色；
- 渐变 / 特效：核心功能 Icon 禁止使用渐变、外发光、立体特效。

**LOGO 色彩**

- 主体色：以品牌专属主色为核心，定义品牌第一视觉印象；
- 拓展色：辅助色仅做点缀，不能盖过主色；
- 渐变 / 特效：印刷、正式物料中禁用复杂渐变；线上场景可轻度使用，但不能破坏轮廓识别。

### 3.3 正反案例汇总

- ✅ **通用正面**：配色克制、语义清晰、单色模式完整、对比度达标
- ❌ **通用反面**：色彩杂乱、低对比度看不清、黑白模式形态残缺、特效堆砌

## 四、尺寸、格式与落地输出通用准则

### 4.1 尺寸适配通用要求

**极小尺寸测试（必测项）**

- Icon：缩至 16dp/24dp，轮廓、线条无粘连、无模糊；触控热区严格遵循 44dp 最小标准。
- LOGO：缩至 16px（Favicon、头像），核心造型与记忆点完整可辨。

**大尺寸适配**

- Icon：不单独放大作为主视觉，放大后仅保留装饰作用，不改变原有形态。
- LOGO：放大至户外广告、展板等超大尺寸，比例不变、细节协调，远距离可识别。

### 4.2 文件格式规范（统一输出标准）

| 应用场景 | Icon 推荐格式 | LOGO 推荐格式 | 通用约束 |
|----------|--------------|--------------|----------|
| 网页 / UI 界面 | SVG（首选）、透明底 PNG | SVG（首选）、透明底 PNG | 矢量格式优先，保证无损缩放 |
| 移动端 APP | 多倍率 PNG（@2x/@3x） | 多倍率 PNG、矢量文件 | 统一透明底色，无杂边、无白边 |
| 桌面图标 / Favicon | ICO（多尺寸合集） | ICO、PNG | 包含多套标准尺寸，适配系统要求 |
| 印刷 / 线下物料 | 高清 PNG、AI 矢量源文件 | AI/EPS 矢量源文件 | 矢量文件为交付标配，保证印刷精度 |

### 4.3 命名通用规范

统一命名逻辑，便于团队协作与文件管理：

- **格式**：`类型-名称-状态-尺寸`
- **Icon 示例**：`icon-search-normal-24dp`、`icon-delete-warning-24dp`
- **LOGO 示例**：`logo-main-full`（标准版组合标）、`logo-icon-simple`（纯图形极简版）
- ❌ **禁止**：中文命名、无规则拼音、乱序命名、重复命名。

## 五、用户体验 & 测试验收 通用标准

### 5.1 通用设计底线（二者均不可违反）

- **识别底线**：普通用户第一眼可理解用途 / 身份，识别率 ≥ 90%
- **记忆底线**：核心特征简单易懂，短时展示后可复述形态
- **适配底线**：多设备、多背景、明暗模式下显示正常
- **合规底线**：无地域、宗教、文化禁忌图形与色彩，跨场景通用

### 5.2 分类型专项测试项

**Icon 专项测试**

- 识别测试：0.5~1 秒快速展示，判断功能含义
- 交互测试：触控热区测试，无点击失灵、误触问题
- 界面融合测试：高密度排布下，视觉舒适、互不干扰

**LOGO 专项测试**

- 记忆测试：3 秒展示后遮挡，可清晰描述核心特征
- 竞品区分测试：与同行业品牌混排，无视觉混淆
- 场景测试：线上屏幕、纸质印刷、远距离场景全部适配

### 5.3 统一不合格判定标准

出现以下任意问题，设计方案驳回返工：

- 语义模糊，多数用户无法理解含义 / 归属；
- 小尺寸下轮廓糊化、细节丢失、无法识别；
- 色彩对比度不足，暗光 / 浅色背景难以分辨；
- 单色模式下结构残缺、形态崩坏；
- 风格混乱、元素堆砌，视觉体验差；
- 触碰文化、地域、宗教禁忌。

## 六、通用设计原则总览（精简执行版）

### 6.1 五大通用黄金原则（Icon + LOGO 通用）

1. **识别优先**：一切设计服务于用户识别，创意、美观让步于可读性
2. **极简克制**：精简元素、减少细节、拒绝堆砌与过度特效
3. **统一协调**：同体系视觉参数（线条、圆角、配色、间距）保持一致
4. **场景兼容**：兼顾大小尺寸、线上线下、明暗模式等全使用场景
5. **用户心智**：贴合行业固有认知，不刻意颠覆大众习惯

### 6.2 差异化设计口诀（快速区分执行）

- **做 Icon**：重通用、重功能、重交互、守标准
- **做 LOGO**：重独特、重记忆、重品牌、强差异
