# Delivery Recipes — 交付配方

本手册说明如何将 skill 生成的 SVG 通过 `svg2icon` CLI 转换为正式交付成果。

## 1. 通用原则

- 源文件永远是 `.svg`。
- 位图和平台格式均由 CLI 派生。
- 导出前自动质量检查。
- 正式变体使用 `primary / mono / reversed`。
- 文件名自动从 SVG 文件名生成。

## 2. Logo 交付包

适用于品牌标志、网站标志、社媒头像、favicon。

```bash
./bin/svg2icon-linux \
  --svg brand-mark.svg \
  --variants primary,mono,reversed \
  --sizes 512,256,128,64,32,16 \
  -f png,ico \
  -o dist/logo
```

输出示例：

```text
dist/logo/
  brand-mark-primary-512x512.png
  brand-mark-primary-256x256.png
  brand-mark-primary-128x128.png
  brand-mark-primary-64x64.png
  brand-mark-primary-32x32.png
  brand-mark-primary-16x16.png
  brand-mark-mono-512x512.png
  brand-mark-reversed-512x512.png
  brand-mark-primary.ico
  brand-mark-mono.ico
  brand-mark-reversed.ico
```

## 3. App Icon 交付包

适用于 macOS、Windows、桌面端、启动器图标。

```bash
./bin/svg2icon-linux \
  --svg app-icon.svg \
  --variants primary \
  --sizes 1024,512,256,128,64,32,16 \
  -f png,ico,icns \
  -x 4 \
  -o dist/app-icon
```

注意：

- App Icon 一般以主版本为主，不一定需要 mono/reversed。
- 如果用于品牌手册，可以额外导出 mono/reversed。
- ICNS 尺寸必须是平台支持尺寸。

## 4. Functional Icon Set 交付包

适用于 UI 图标组。

```bash
for svg in assets/icons/*.svg; do
  ./bin/svg2icon-linux \
    --svg "$svg" \
    --variants primary,mono,reversed \
    --sizes 64,32,24,16 \
    -f png \
    -o dist/icons
 done
```

建议：

- UI 图标仍应保留 SVG 源文件给前端直接使用。
- PNG 主要用于预览、文档或不支持 SVG 的环境。
- 图标组必须先通过 `functional-icon-grid.md` 检查统一性。

## 5. Favicon 配方

```bash
./bin/svg2icon-linux \
  --svg favicon.svg \
  --variants primary,mono \
  --sizes 256,128,64,48,32,16 \
  -f png,ico \
  -o dist/favicon
```

## 6. 社交媒体头像配方

```bash
./bin/svg2icon-linux \
  --svg social-avatar.svg \
  --variants primary \
  --sizes 1024,512,256 \
  -f png,jpg \
  --bg '#ffffff' \
  -o dist/social
```

## 7. 深色模式反白包

```bash
./bin/svg2icon-linux \
  --svg brand-mark.svg \
  --variants reversed \
  --sizes 512,256,128,64 \
  -f png \
  -o dist/dark-mode
```

## 10. 不推荐交付方式

❌ 只交付 PNG，不交付 SVG。  
❌ 手动改名，导致源文件和导出文件对应不上。  
❌ 用截图或设计软件导出替代 CLI。  
❌ 使用负片 `invert` 当作正式反白版。  
❌ 让不同图标使用不同尺寸规则。
