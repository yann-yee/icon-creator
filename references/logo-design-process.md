# Logo 设计全流程参考

来源：知乎「从概念到落地 - Logo 设计指南（内附大量学习资源）」— Newsbolt 案例

## 完整 7 步流程

### Step 1: 理解设计概要 (Design Brief)

**必填清单：**
- [ ] **项目目标**：项目是否具有必须达到的具体目标？
- [ ] **可交付成果**：项目完成后预期的交付成果是什么？
- [ ] **时间表**：是否有期望完成的时间节点？
- [ ] **项目利益相关者**：谁参与项目决策？
- [ ] **目标受众**：Logo 应与哪些人群共鸣？
- [ ] **产品或公司简介**：产品/公司的目的是什么？带来什么价值？
- [ ] **品牌定位声明**：品牌对消费者承诺的核心是什么？与竞品的关系？
- [ ] **预算和付款**：是否有项目预算？如何处理付款？

### Step 2: 视觉研究与艺术指导

**视觉研究：**
- 浏览艺术和设计相关数据（Dribbble、LogoLounge、设计杂志）
- 参观博物馆、画廊，进行跨领域灵感收集
- **关键词提炼**：将收集到的参考提炼为 3 个核心关键词

**情绪板 (Moodboard)：**
- 收集 5~10 张能代表品牌调性的图片
- 用工具（如 Sketch）快速组织为情景拼图
- 呈现给客户确认方向

**艺术指导：**
通过使用主题、情感和视觉思维，提炼简明的艺术意图规划。
- 确定视觉风格方向（极简/繁复/自然/科技）
- 明确情感基调（专业/亲和/激进/宁静）

### Step 3: 理念与头脑风暴

**头脑风暴方法——Translating：**
- 不看参考物，用最简单的线条捕捉概念
- 从功能描述转向可视觉化的隐喻
- 快速记录所有想法，不做评判

**创意方向筛选：**
- 将概念缩到最小可行（Minimum Viable Concept）
- 每个概念用一句话解释隐喻故事

### Step 4: 素描 (Sketches)

即使最基本的草图也是 logo 设计过程中的重要组成部分。
- 快速、粗略地探索多种创意方向
- 不考虑完成度和精细度
- 一个 A4 纸上可画 6~12 个缩略草图
- **专业技巧**：在构思和草图阶段，通过黑白逆转寻找设计瑕疵

### Step 5: 数字细化 (Digitization)

使用矢量工具将草图转化为精确的图形。

**Adobe Illustrator 关键工具（对应 SVG 实现）：**
| AI 工具 | SVG 等价实现 |
|---------|-------------|
| 基本形状工具 | `<circle>`, `<rect>`, `<polygon>`, `<path>` |
| 对齐工具 | 手动计算坐标对齐（利用 8×8 网格系统） |
| Pathfinder | 复合路径 `fill-rule="evenodd"`，或 `<mask>` 叠加 |
| Shape Builder | 多条 `<path>` 的组合与嵌套 `<g>` |
| 钢笔工具 | `<path d="M... C... Q...">` 贝塞尔曲线 |

### Step 6: 配色方案 (Color)

**颜色资源推荐：**
- **Ctrl + Paint**：概念艺术家 Matt Kohr 的视频教程，从数字绘画角度解释颜色选择和混合
- **COLOURlovers**：全球艺术家和设计师分享配色方案的创意社区
- **Adobe Color CC**：使用色盘创建配色方案，浏览社区数千种颜色组合
- **Pinterest**：现成的配色方案，观察色彩趋势

**配色注意事项：**
- 徽标最终必须离开设计软件的舒适范围（「那里永远存在白色空间，而现实并不如此」）
- 在深色和浅色、白色和黑色背景下测试可读性
- **黑白转换测试**：黑白转换很容易暴露设计缺陷或意想不到的象征意义

### Step 7: 组织和交付文件

**交付格式：**
| 用途 | 格式 | 说明 |
|------|------|------|
| 打印 | EPS, SVG, AI, PDF | 矢量格式，无限缩放不失真 |
| Web | SVG, JPEG, PNG, GIF | SVG 优先；多色渐变用 JPEG；平坦颜色用 PNG |
| 开发 | SVG | 自包含、可缩放 |

**文件夹规范：**
```
assets/
  logo/
    brand-primary.svg    # 标准版（品牌色）
    brand-mono.svg       # 单色版（纯黑）
    brand-reversed.svg   # 反白版（纯白）
    brand-guide.pdf      # 1 页基础使用规范
```

## 增值交付

### 提供基础风格指南 (1 Page Brand Guide)
- Logo 最小使用尺寸
- 安全空间（Clear Space）
- 正确与错误使用示例
- 深色/浅色背景下的使用规范

### 使用微妙的动画 (Micro Animation)
- 在适当环境下赋予 logo 以生命和意义
- 示例：SVG 路径生长动画 `stroke-dasharray` + `stroke-dashoffset`
- 注意：动画不应该干扰品牌信息的传达

## 设计原则检查

- **对独创性和创造性的呼唤**：避免跟随行业领导者，敢于在 logo 设计过程中倡导创新
- **LogoLounge 年度趋势报告**：关注最新的 logo 设计趋势，保持知识更新
