# Product Meaning & Aesthetic Thesis

本参考用于解决 Icon Creator V2 的两个核心问题：

1. 不理解产品，只根据表面关键词画“行业图标”；
2. 没有美学内核，只根据“极简 / 科技 / 高级”等 style tag 拼装视觉。

---

# 1. Product Meaning Model

一个视觉资产至少要知道它在代表什么变化，而不仅是代表什么物件。

## 1.1 Essence

用一句话描述产品/功能的本质。

弱：

```text
一个网络管理软件。
```

强：

```text
把复杂、动态的网络状态压缩成可理解、可控制的系统视图。
```

## 1.2 User Job

用户不是“使用某个功能”，而是在完成某种任务。

例如：

```text
发现未知设备
确认系统是否健康
恢复丢失的数据
从复杂信息中找到下一步行动
```

## 1.3 Transformation

优先寻找 Before → After。

示例：

```text
unknown → discovered
fragmented → organized
uncertain → protected
complex → clear
manual → automatic
isolated → connected
chaotic → controlled
```

Transformation 往往比行业物件更适合作为 Symbol Territory 的来源。

## 1.4 Differentiator

问：同类产品都能做什么，而这个产品真正值得记住的不同是什么？

没有差异点时，视觉很容易退化为通用行业符号。

Differentiator 可以来自：

- 产品机制；
- 用户体验；
- 工作方式；
- 性能 / 自动化 / 可靠性；
- 特殊目标人群；
- 独特哲学。

## 1.5 Anti-Meaning

明确最不能被误解成什么。

例如：

```text
不是交易平台
不是社交网络
不是游戏工具
不是安全/军工产品
```

Anti-Meaning 会直接限制符号 territory。

---

# 2. From Product Meaning to Aesthetic Meaning

产品含义回答“它是什么”；Aesthetic Thesis 回答“它应该以什么人格被感知”。

不要直接从产品类别跳到风格。

错误：

```text
AI 产品 → 紫色渐变 + sparkle
网络产品 → 蓝色节点 + 六边形
安全产品 → 盾牌
金融产品 → 金色
```

正确链路：

```text
Product promise
→ desired emotional response
→ visual tension
→ form consequences
```

---

# 3. Emotional Promise

视觉第一次出现时，希望用户产生什么感受？

不是列 8 个形容词，而是选最重要的一到两个：

- confidence
- calm
- curiosity
- precision
- energy
- warmth
- control
- trust
- momentum
- clarity

这些必须能够追溯到产品体验。

---

# 4. Visual Tension

高质量美学通常不是单一形容词，而是两股力量的平衡。

常见 tension：

```text
Technical × Human
Powerful × Quiet
Precise × Organic
Playful × Serious
Dense × Calm
Stable × Dynamic
Familiar × Distinctive
Premium × Approachable
Industrial × Refined
Minimal × Expressive
```

## 为什么 tension 有用

“科技感”会让模型回归平均答案。

“Technical × Human”则迫使设计同时回答：

- 哪里表现技术精确？
- 哪里避免机械冰冷？

于是会产生真实 form decisions。

---

# 5. Anti-Aesthetic

生成式设计必须主动压制 clichés。

常见 Anti-Aesthetic：

```text
Generic SaaS
AI sparkle / brain / neural-network cliché
Crypto / Web3
Gaming aggression
Childish toy
Enterprise legacy
Cyberpunk neon
Luxury black-and-gold
Medical cross/shield cliché
Random gradient blob
```

Anti-Aesthetic 不是“我不喜欢某风格”，而是：

> 这种视觉会让用户对产品形成错误人格判断。

---

# 6. Aesthetic Thesis Format

推荐格式：

```markdown
## Aesthetic Thesis

[一句或两句有张力的判断]

Emotional promise:
...

Visual tension:
A × B

Anti-aesthetic:
- ...
- ...

Formal consequences:
- silhouette:
- geometry:
- corners:
- weight:
- negative space:
- color behavior:
- motion/depth:
```

示例：

```text
Precise, but not sterile.
Quiet, but unmistakably technical.

Emotional promise:
control and confidence

Visual tension:
Technical × Human

Anti-aesthetic:
- generic infrastructure SaaS
- cyberpunk
- aggressive security tooling

Formal consequences:
- stable compact silhouette
- simple geometry with slight optical asymmetry
- softened transitions, not bubbly corners
- medium visual weight
- generous negative space
- restrained cool palette with one controlled accent
```

---

# 7. Deriving Form from Thesis

不要先选 Bauhaus / Swiss / cyber / flat，再解释为什么。

应该从 thesis 推导。

## Shape

- Stable → compact closed shapes
- Dynamic → directional or evolving contours
- Human → slight irregularity / softer transition / approachable proportions
- Technical → controlled geometry / precision / modular rhythm

## Corners

- sharp → decisiveness, speed, engineering
- medium radius → approachable precision
- large radius → softness, friendliness, consumer warmth

不要简单把“现代”等于“大圆角”。

## Symmetry

- strict symmetry → stability, institution, permanence
- controlled asymmetry → motion, intelligence, human touch

## Negative Space

负形可以承载第二层意义，但必须在主轮廓成立后才使用。

隐藏符号如果只有设计师能发现，不应成为核心 concept justification。

## Color

颜色来自人格和产品 context，不来自行业刻板印象。

优先确定：

```text
temperature
saturation
contrast
accent strategy
mono behavior
```

再选择具体 hex。

---

# 8. Geometry Is a Tool

黄金比例、Fibonacci、√2、模块网格都可以使用，但没有任何一个比例自动产生美感。

使用几何前问：

```text
这个比例在解决什么视觉关系？
```

合理：

```text
为了让三层结构产生明显但不突兀的尺度递进，测试 1.5–1.7 的级差，再依据 optical weight 选最终值。
```

不合理：

```text
因为黄金比例高级，所以必须 1.618。
```

最终判断优先级：

```text
Intent
> optical balance
> system consistency
> mathematical elegance
```

---

# 9. Aesthetic Failure Signals

出现这些信号时，应回到 thesis：

- 只能用“高级、现代、科技”解释设计；
- 换成任意同类 SaaS 名称仍成立；
- 设计理由主要是黄金比例/网格；
- 依赖渐变或特效掩盖普通轮廓；
- 每个 product keyword 都对应一个图形元素；
- 不知道为什么某处必须圆角/锐角；
- 与 `DESIGN.md` 现有视觉人格冲突。

---

# 10. Readiness Gate

进入 Symbol Strategy 前，应至少能回答：

- Product Essence 是什么；
- 最重要的 Before → After 是什么；
- 一个真正有意义的 Differentiator；
- Emotional Promise；
- Visual Tension；
- 至少一个 Anti-Aesthetic。

不要求完美品牌战略，只要求足够支撑当前视觉决策。
