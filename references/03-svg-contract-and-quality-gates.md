# SVG Contract & Quality Gates — SVG 合约与质量门禁

本手册定义 `icon-creator` 生成 SVG 的硬性合约，以及 `svg2icon` CLI 导出前应检查的内容。

## 1. 标准 SVG 外壳

所有源 SVG 必须使用：

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="512" height="512" viewBox="0 0 512 512" shape-rendering="geometricPrecision">
```

推荐结构：

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="512" height="512" viewBox="0 0 512 512" shape-rendering="geometricPrecision">
  <title>Brand mark</title>
  <desc>Geometric logo mark generated by icon-creator.</desc>
  <defs>
    <!-- gradients / masks only when necessary -->
  </defs>
  <g id="background">
    <!-- optional app icon backing shape -->
  </g>
  <g id="symbol">
    <!-- main mark paths -->
  </g>
</svg>
```

## 2. 硬性禁止

不得出现：

- `<image>`
- `data:image/png;base64,...`
- 外部 `href` 图片资源
- 外部 CSS
- 外部字体文件
- 依赖系统字体的最终 `<text>`
- 过度滤镜：复杂 blur、noise、texture、bitmap-like effect

## 3. 坐标与几何

- 主坐标使用 512 画板。
- 关键点优先对齐 8×8 逻辑网格：64px 单元。
- 细节对齐 4px 精度网格。
- 描边宽度建议：12 / 16 / 20 / 24 / 32 / 40 / 48。
- 圆角建议：8 / 12 / 16 / 24 / 32 / 48。
- 小数最多保留 2 位。

## 4. 自动质量门禁

CLI 导出前应阻断以下错误：

| 检查项 | 级别 | 说明 |
|---|---|---|
| `viewBox` 不是 `0 0 512 512` | Error | 源画板不统一 |
| 缺少 `viewBox` | Error | 无法稳定缩放 |
| 出现 `<image>` | Error | 不允许位图嵌入 |
| 出现 `data:image/` | Error | 不允许 base64 位图 |
| 出现外部 `href` | Error | 不允许依赖外部资源 |
| SVG XML 无法解析 | Error | 文件不可用 |
| `width / height` 非 512 | Warning | 可导出但建议修正 |
| 缺少 `shape-rendering` | Warning | 建议添加 |
| 出现 `<text>` | Warning | 建议转 path |

## 5. 人工设计门禁

自动检查只能判断文件合规，不能判断设计好坏。交付前还需要人工设计门禁：

### 5.1 Logo

- 是否有唯一记忆点？
- 是否能单色成立？
- 是否能横向 / 竖向组合？
- 是否不像竞品？
- 是否能解释品牌差异？

### 5.2 App Icon

- 48px 下是否可读？
- 主体是否在安全区内？
- 圆角裁切后是否稳定？
- 深浅背景中是否都有足够对比？
- 是否避免了长文字？

### 5.3 Functional Icon Set

- 线宽是否统一？
- 圆角和端点是否统一？
- 视觉重量是否统一？
- 相似功能是否有足够差异？
- 状态版本是否规则一致？

## 6. 质量评分表

每项 0–2 分，总分 20 分。低于 16 分不建议交付。

| 项目 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 识别性 | 看不懂 | 需解释 | 一眼可懂 |
| 简洁性 | 过度复杂 | 基本可用 | 高度凝练 |
| 独特性 | 模板化 | 有少量差异 | 记忆点明确 |
| 小尺寸 | 不可读 | 勉强可读 | 清晰可读 |
| 单色 | 失效 | 可辨但弱 | 完全成立 |
| 反白 | 失效 | 可辨但弱 | 完全成立 |
| 几何 | 混乱 | 基本整齐 | 数学统一 |
| SVG 合规 | 多项问题 | 有警告 | 完全合规 |
| 系统一致 | 不统一 | 部分统一 | 完全统一 |
| 交付完整 | 缺文件 | 基本完整 | 变体齐全 |

## 7. 推荐检查命令

```bash
./bin/svg2icon-linux --svg logo.svg --check-only
```

通过后再导出：

```bash
./bin/svg2icon-linux --svg logo.svg --variants primary,mono,reversed --sizes 512,256,128,64,32 -f png,ico -o dist/
```
